# DESENVOLVIMENTO MOBILE — PROJETO GUIADO

## O app que você vai entregar

UP Campus+ — Agenda Acadêmica

- Tela inicial.
- Cadastro de eventos: nome, data, local e descrição.
- Lista de eventos.
- Detalhes de um evento.
- Editar e excluir.
- Favoritar.
- Dados continuam após fechar o app.
- Tela Sobre.
- APK final + demonstração do funcionamento.

## Nossa versão do laboratório

Android Studio Giraffe | 2022.3.1

- Todos os caminhos de menu e telas deste roteiro foram pensados para o ambiente Giraffe.
- Projeto principal: XML/Views + Kotlin, porque cobre diretamente o plano de ensino.
- Room entra como evolução da persistência local.
- Compose aparece no final como comparação moderna, sem quebrar o app principal.
